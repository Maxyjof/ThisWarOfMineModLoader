# 开局物资实测包

这是给玩家验证枪械、弹药、工具和防护装备是否能在实战中使用的临时测试模组，不是平衡性模组

## 发放内容

- 40种新增枪械各1把
- 4种弹药补给物品各1件
- 2种防护装备与4种野战工具各1件
- 手枪弹`PistolShells`、霰弹`ShotgunAmmo`、步枪弹`RifleAmmo`和通用弹药`Ammo`各30发

新物品必须对应安装并启用的“更多枪械模组”“弹药补给模组”和“野战工具与防护装备”。本测试包也依赖“军火交易扩展”，确保测试组合覆盖该模组

## 安装和测试

将此ZIP与依赖模组ZIP一同放入游戏目录的`Mods`文件夹，在模组管理界面启用后点击“重启并应用”。每个新战役首次完成庇护所场景初始化时，模组会把物资补足到共享物品栏。打开“我们的物品”查看，再由幸存者带去夜间搜刮测试。读取已有存档时不会重新发放，避免把已带进夜间背包的枪械补进仓库

本模组通过已核验的`dweller:AddItems`原生接口增加共享物资，并在发放前确认所有54种物品均已注册。它逐项读取库存，只补足到目标数量。昼夜开始事件仅用于尚未完成发放时重试，不会再次开启发放。存档载入状态由当前游戏的`IsJustLoadedGame`原生标记判定，不使用整个加载器安装共用的领取标记

仅在新战役第1天场景初始化时补足物资；读取第1天存档时也不会重新发放。若初始化时物品配置尚未就绪，会在后续昼夜开始事件重试

## 实测边界

物品注册成功不等于枪械已能正确开火、子弹已绑定每种新枪、装备效果正确或交易货单可用。请分别记录背包图标、装备与工具行为、弹药消耗、搜刮和交易结果。弹药配置目前没有经过核验的逐枪消耗绑定
