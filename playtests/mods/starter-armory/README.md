# 开局物资实测包

这是给玩家验证枪械、弹药、工具和防护装备是否能在实战中使用的临时测试模组，不是平衡性模组

## 发放内容

- 40种新增枪械各1把
- 4种弹药补给物品各1件
- 2种防护装备与4种野战工具各1件
- 手枪弹`PistolShells`、霰弹`ShotgunAmmo`、步枪弹`RifleAmmo`和通用弹药`Ammo`各30发

新物品必须对应安装并启用的“更多枪械模组”“弹药补给模组”和“野战工具与防护装备”。本测试包也依赖“军火交易扩展”，确保测试组合覆盖该模组

## 安装和测试

将此ZIP与依赖模组ZIP一同放入游戏目录的`Mods`文件夹，在模组管理界面启用后点击“重启并应用”。建议新建经典模式存档；首次进入第1天庇护所时，物资会放入庇护所共享物品栏。打开“我们的物品”查看，再由幸存者带去夜间搜刮测试

本模组通过已核验的`dweller:AddItems`原生接口增加全局共享物资，并在发放前确认所有54种物品均已注册。它不会把物资只塞进夜间搜刮用的角色背包

同一个加载器安装只发放一次，状态保存在`MaxyModLoader/storage/twom.play.starter-armory.*.dat`。再次测试前，退出游戏并删除这两个模组专属数据文件，或在新的加载器安装中使用；不要在游戏运行时编辑存储文件

## 实测边界

物品注册成功不等于枪械已能正确开火、子弹已绑定每种新枪、装备效果正确或交易货单可用。请分别记录背包图标、装备与工具行为、弹药消耗、搜刮和交易结果。弹药配置目前没有经过核验的逐枪消耗绑定
