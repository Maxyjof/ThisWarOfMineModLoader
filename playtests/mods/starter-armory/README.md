# 开局物资实测包

这是给玩家验证枪械、弹药、工具和防护装备是否能在实战中使用的临时测试模组，不是平衡性模组

## 发放内容

- 40种新增枪械各1把
- 4种弹药补给物品各1件
- 2种防护装备与4种野战工具各1件
- 手枪弹`PistolShells`、霰弹`ShotgunAmmo`、步枪弹`RifleAmmo`和通用弹药`Ammo`各30发

新物品必须对应安装并启用的“更多枪械模组”“弹药补给模组”和“野战工具与防护装备”。本测试包也依赖“军火交易扩展”，确保测试组合覆盖该模组

## 安装和测试

将此ZIP与依赖模组ZIP一同放入游戏目录的`Mods`文件夹，在模组管理界面启用后点击“重启并应用”。当前实现会在本次运行中首次就绪的第1天场景尝试发放物资，同一游戏日只尝试一次，未完成项在后续游戏日重试。打开“我们的物品”查看，再由幸存者带去夜间搜刮测试

本模组通过已核验的`dweller:AddItems`原生接口增加共享物资，并在发放前确认所有54种物品均已注册。它逐项读取库存，只补足到目标数量；单项原生写入或数量核验失败时继续处理其他项目，并输出失败名称与原因，后续游戏日只重试未达标项。同一游戏日的昼夜与场景事件不会重复尝试。原生`IsJustLoadedGame`在新战役首日也返回真，不能用来识别已有存档，因此本包不把它当作存档判断依据

当前游戏桥没有可区分“新战役”和“首日存档载入”的稳定标识。新开局的发放已按场景首次就绪触发；继续载入第1天存档时可能再次补足已带走的物品。此边界需待接入已核验的新战役生命周期信号后才能消除。若初始化时物品配置尚未就绪，会在后续昼夜开始事件重试

## 实测边界

物品注册成功不等于枪械已能正确开火、子弹已绑定每种新枪、装备效果正确或交易货单可用。请分别记录背包图标、装备与工具行为、弹药消耗、搜刮和交易结果。弹药配置目前没有经过核验的逐枪消耗绑定
