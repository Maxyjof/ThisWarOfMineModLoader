# 生存营地辅助包

由营养、开局补给和疲劳恢复模块组成，调整基础生存数值并记录应用结果。

## 功能

- 默认将每日饥饿增长调整为原来的50%
- 首次进入有角色的庇护所时发放两个罐头
- 新一天开始时为每名角色减轻10点疲劳
- 将营养、补给和恢复拆为三个可配置模块

## 配置

在`mod.json`的`settings`中调整`hunger_factor`、`starter_food`和`daily_tired_relief`。补给仅按进程限制一次，重新启动游戏会重新允许领取。

## 兼容性

面向Steam版BuildID22193501，依赖游戏事件与测试记录桥。与其他修改相同角色参数或物资的模组一起使用时，结果受加载顺序影响。
