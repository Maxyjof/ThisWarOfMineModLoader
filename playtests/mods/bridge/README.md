# MaxyModLoader游戏事件适配器

本模组为经过本机游戏Lua脚本核验的场景、昼夜、搜刮状态保存、广播和建造回调发布事件。事件仅覆盖经过对应Lua函数的调用路径。`game.scavenge.saving`仅表示离开搜刮场景时调用`OnSaveScavengeState`，不代表通用存档钩子。

加载器的`context.schedule`可依赖此桥发布的`game.day.begin`安排按游戏日触发的任务。任务在游戏昼夜回调中执行，不是后台计时器。

这是官方内容模组依赖的游戏事件适配层，通过包装本机已确认的昼夜、角色、搜刮与制作回调发布事件，并读取真实场景快照。它提供模组间事件、服务发现和有限的运行记录，不属于玩法演示模组。

## 功能

- 记录庇护所昼夜、角色初始化、搜刮和制作回调
- 向声明依赖的模组提供遥测服务
- 把记录写入加载器目录，不修改游戏存档

## 使用说明

这是开局物资实测包依赖的基础服务。单独启用时只发布游戏事件和记录数据，不调整物资、角色属性或动作速度。

## 兼容性

面向Steam版BuildID22193501。不同游戏版本的Lua类和回调可能变化；事件记录只覆盖本模组明确包装的入口。
