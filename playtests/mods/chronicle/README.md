# 营地活动记录包

依赖事件桥记录游戏活动，并在昼夜回调中生成受容量限制的日志和摘要。

## 记录内容

| 分类 | 收到回调时记录 | 汇总用途 |
|:---|:---|:---|
| 搜刮 | 开始与完成 | 统计搜刮活动 |
| 制作 | 开始与完成 | 统计制作活动 |
| 场景 | 进入与离开 | 保留活动上下文 |
| 昼夜 | 白天结束 | 整理当日摘要 |

## 使用流程

1. 先启用**游戏事件与测试记录桥**
2. 在清单里设置记录容量
   - 默认最多保留500条
   - 旧记录超过容量时被移除
3. 正常进行游戏，等待真实回调写入记录

> 活动日志只反映实际收到的回调，不是完整存档，也不保证所有游戏动作都有记录

## 使用说明

本模组依赖**游戏事件与测试记录桥**。清单默认保留500条记录；日志属于本次游戏进程数据，不作为存档进度。

内部模块通过`context.require`共享日志服务。开发者可用下面的入口形式订阅事件：

```lua
return {
    on_load = function(context)
        --处理事件时读取实际收到的数据
        context.events.on('loader.ready', function()
            context.log('模组已就绪')
        end)
    end
}
```

## 兼容性

面向Steam版BuildID22193501。仅记录事件桥实际收到的回调。
