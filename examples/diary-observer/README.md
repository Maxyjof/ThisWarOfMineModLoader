# 游戏日记事件观察示例

观察游戏已有的`logEvent`Lua函数，并通过加载器事件总线发布`game.diary`事件。

## 运行行为

- 在调用原函数前复制现有事件参数
- 保留原函数的返回值与原有行为
- 将观察到的记录通知其他订阅`game.diary`的模组

## 覆盖范围

本示例只观察经过该Lua函数的记录，不代表完整原生日记系统。它不读取或改写玩家日记存档，也不伪造其他游戏事件。

## 兼容性

面向已经核验的Steam版BuildID22193501。游戏更新可能改动函数名、参数或包装关系。

## 文件

- `main.lua`：包装原函数并广播事件
- `mod.json`：名称、版本、功能和兼容性清单
