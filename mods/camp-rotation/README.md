# 营地轮休制度

每逢第3个游戏日，在昼夜切换完成且队伍位于庇护所时，模组会检查全体幸存者，选择疲劳最高的一人，降低最多12点疲劳。只有疲劳至少25点时才会实际恢复。当天没有需要轮休的人也会记下检查结果，避免重复检查。

原生ModTools可以修改静态角色参数，但不能在真实昼夜事件中选出当前最疲惫的成员、修改其状态并跨游戏启动记住最近处理的游戏日。本模组组合使用加载器的游戏事件、角色领域API和每模组隔离的持久存储；它不修改存档文件。

轮休只发生在`game.day.begin`之后、`context.game.phase.current()`返回`shelter`且不是上一夜搜刮归来的事件。使用新存档或等待第3个游戏日测试。模组数据保存在`MaxyModLoader/storage/twom.play.camp-rotation.*.dat`；重置模组轮休记录时退出游戏后删除这两个文件。

依赖`MaxyModLoader游戏事件适配器`，要求Steam BuildID22193501与MaxyModLoader Modding API 1.2.0。自动测试覆盖日期门槛、疲劳选择和重复事件保护；实机恢复幅度仍需游戏内验证。
