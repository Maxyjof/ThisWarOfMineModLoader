# 营地参谋MCP

这个模组将MaxyModLoader的结构化MCP动作接到真实游戏状态上，让已连接的本机可信AI客户端可以读取营地、有限地安排一名成员休息，或为下一次搜刮切换战术。官方ModTools没有运行中的AI动作注册和游戏主线程调用入口。

| MCP动作 | 用途 | 限制 |
| --- | --- | --- |
| `shelter_report` | 返回游戏日和幸存者饥饿、疲劳、疾病、伤势 | 只读，仅限庇护所阶段 |
| `rest_survivor` | 降低指定成员疲劳 | 幸存者序号必须有效，每次只能降低5至20点，仅限庇护所阶段 |
| `set_scavenge_mode` | 调整“疲劳与搜刮战术”的共享规则 | 仅接受`careful`、`balanced`、`urgent`，下一次搜刮开始时生效 |

动作在游戏Lua主线程执行，模组会在调用时再次核验阶段、角色序号和数值范围。MCP连接不是权限沙箱；只安装信任的模组和客户端。

依赖`MaxyModLoader游戏事件适配器`和`疲劳与搜刮战术`，并要求启用加载器内置MCP。自动测试会模拟工具发现后的有效调用、非法参数和非庇护所阶段拒绝；实际客户端连接需在游戏运行后验证。
