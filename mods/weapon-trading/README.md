# 军火交易扩展

将更多枪械模组中的精选枪械加入四种原版商人货单：普通商人、综合商人、军营商人与绑架者商人。库存概率和价格倍率各自配置，仍受原版商人刷新与每日出售价值规则限制。

## 货单

- 普通商人出售手枪与紧凑型武器
- 综合商人出售冲锋枪、霰弹枪和步枪
- 军营商人出售突击步枪、精确步枪与轻机枪
- 绑架者商人出售高威力枪械和霰弹枪

## 调整

打开`native-content.json`修改商人标识、出现概率、交易价格倍率和单次数量。重新构建后才会生效。

## 依赖

需要`twom.content.more-guns`提供相应物品。补丁沿用原版`TradingConfig.xml`公开结构，不添加新商人，也不绕开原版库存限制。
