# 弹药补给模组

增加4种使用项目原创图标的弹药补给，沿用适配的原版弹药物品模板。它们可以制作，并按清单加入原版地点搜刮表。

## 物品清单

- **9mm弹药**：原创图标格1，堆叠上限60，价值16。制作耗时1小时，消耗火药×16、武器零件×2。搜刮表LootGen_Map11。
- **12号霰弹**：原创图标格2，堆叠上限60，价值20。制作耗时1.25小时，消耗火药×18、武器零件×2。搜刮表LootGen_Map06_guns。
- **步枪弹药补给**：原创图标格3，堆叠上限60，价值18。制作耗时1.5小时，消耗火药×16、武器零件×2。搜刮表LootGen_Map09_R_guns。
- **混合弹药箱**：原创图标格4，堆叠上限60，价值30。制作耗时1.75小时，消耗火药×30、武器零件×3。搜刮表LootGen_Map07。

## 兼容边界

各弹药的图标、堆叠数、价值、配方和搜刮位置可在native-content.json中调整。新增物品沿用对应的原版弹药行为。当前没有经过实测的字段可以把这些补给绑定到特定枪械的弹药消耗，本模组不会声称或改写这项行为。
