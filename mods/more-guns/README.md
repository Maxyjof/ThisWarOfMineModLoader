# 更多枪械模组

新增40种枪械，全部使用项目原创物品图标。枪械采用适配的原版物品模板，因此沿用对应模型、动作与操作行为；每把枪的伤害、射击间隔、冷却、价值、配方和投放地点均单独配置。

## 枪械与搜刮地点

地图掉落加入原版地点生成器。每个生成器的新增物品数量为0至1件，因此属于有机会搜到，不保证每次进入都出现。图标格号从1开始，配置中的iconIndex从0开始。

## 配置与边界

编辑native-content.json可逐枪调整BulletsPerShot、BulletTimeInterval、CooldownTime、WeaponRange、damageMultiplier、价值、图标图集及图标格号，也可调整制作材料和地图生成器。

原创贴图源文件保存在tools/item-art/source。执行tools/build-item-textures.ps1可重建本模组的DDS图集。原生模板负责游戏模型和行为，背包图标使用此模组独立图集，不覆盖原版贴图。

弹药补给模组提供独立的制作和搜刮物品。新增弹药是否被原版或新增枪械消耗尚未验证，因此本模组不修改或承诺弹药绑定。
