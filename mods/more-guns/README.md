# 更多枪械模组

在原版资源基础上加入40种枪械配置，分布于军营、枪械仓库、狙击点、帮派据点、市场与商人地点。掉落由原版地图生成器完成，每个新增条目最多生成一件，最小数量设为零以避免保证性刷枪。

## 枪械清单

### 突击步枪与轻机枪

AK-74、M4A1、FAMAS、G36、SCAR-H、FN FAL、AUG、Galil、SIG SG 550、AN-94、M16A4、AKM、M249、RPK-74

### 冲锋枪

MP5、Uzi、PPSh-41、P90、Vector、UMP-45、MP7、Thompson

### 手枪

Glock 17、USP .45、Five-seveN、Desert Eagle、Beretta 92、M1911、P226、CZ 75

### 霰弹枪

Remington 870、Benelli M4、SPAS-12、Mossberg 500、Saiga-12、双管霰弹枪

### 精确步枪

M14、Dragunov SVD、VSS Vintorez、SKS

## 制作与平衡

所有枪械都能在三级金工台制作，消耗武器零件和材料。每个物品的`native-content.json`条目提供价值、单次弹丸数量、弹丸间隔、冷却时间、射程、伤害倍率和配方字段，可按需修改后重新构建。

## 兼容与视觉说明

物品配置由本机已核验的游戏版本及官方ModTools从原版模板编译。当前复用原版手枪、机枪、霰弹枪和狙击枪的模型、图标、动画与通用弹药逻辑，不附带40套独立外观，也没有把自定义弹药与武器消耗关系改写成未经验证的规则。此模组不新增地图或人物。
