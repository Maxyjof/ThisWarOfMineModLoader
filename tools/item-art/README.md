# 原创物品图标

这组图标由MaxyModLoader项目使用ImageGen原创生成，没有复制游戏原版图集或创意工坊贴图。枪械图集包含40种武器，生存物品图集包含4种弹药、两种防护装备和4种工具

`source`目录保存可重新裁切的透明PNG源图。运行`./tools/build-item-textures.ps1`会将图标按行优先顺序放入1024×1024图集，每格128×128，并输出到对应模组的`resources/UI/MaxyModLoader/Items`目录

武器图集只使用前40格。生存物品源图的前4格用于弹药模组，第5至10格用于野战装备模组。物品清单中的`iconTextureName`和`iconIndex`必须与图集路径及格子编号对应

## 生成提示词

武器源图提示词：

> 创建一张真正透明背景的8列8行原创物品图标图集，前40格按顺序绘制AK-74、M4、FAMAS、G36、SCAR-H、FN FAL、AUG、Galil、SIG SG 550、AN-94、M16A4、AKM、MP5、Uzi、PPSh-41、P90、Vector、UMP45、MP7、Thompson、Glock 17、USP、Five-seveN、Desert Eagle、Beretta 92、M1911、P226、CZ 75、Remington 870、Benelli M4、SPAS-12、Mossberg 500、Saiga-12、双管霰弹枪、M14、Dragunov SVD、VSS Vintorez、SKS、M249、RPK-74。每格为独立的战争生存游戏物品插画，细铅笔线与克制水彩，磨损金属、木材和聚合物，深灰与旧褐色，图标居中并留出透明边距，不要格线、文字、水印或背景

生存物品源图提示词：

> 创建一张真正透明背景的4列4行原创物品图标图集，前10格依次绘制9毫米子弹盒、12号霰弹盒、步枪弹药包、混合弹药铁盒、磨损的加固防弹衣、旧钢盔、重型撬棍、野战镐、手工撬锁工具包和加固铁铲。每格是俯视三分之四角度的战争生存物品插画，铅笔线稿与克制水彩，旧金属、布料、纸盒和木柄，深灰与褐色，不要格线、文字、水印或背景

项目为每项新增物品使用独立命名的原创DDS图集。模型、动作与行为仍由物品声明的适配原版模板提供。图标资源的授权归属为项目原创内容
