# 模组清单和说明文件

清单采用UTF8 JSON。只接受当前字段，未知字段或缺少必填字段会报错；没有旧版清单迁移。所有相对路径必须位于模组目录内，不使用绝对路径、父目录跳转或文件链接。

| 字段 | 用途 | 默认或限制 |
| --- | --- | --- |
| `schemaVersion` | 清单契约 | 必填，必须为1 |
| `id` | 全局唯一标识 | 必填，小写字母开头，各段含小写字母或数字，用点、下划线或连字符连接 |
| `name` | 显示名称 | 必填，非空 |
| `version` | 当前模组版本 | 必填，三段非负整数，不带前导零或预发布后缀 |
| `entry` | Lua入口相对路径 | 默认`main.lua` |
| `enabled` | 无玩家选择时的默认启用状态 | 默认true |
| `author`、`description` | 作者和简述 | 默认空字符串，简述最多16384字符 |
| `descriptionFile` | Markdown详细说明 | `.md`或`.markdown`相对路径 |
| `features` | 功能列表 | 字符串数组，不能有空项 |
| `compatibility`、`license` | 当前游戏限制和许可 | 字符串 |
| `website` | 模组主页 | 空或HTTP/HTTPS绝对URL |
| `dependencies` | 直接依赖及最低版本 | ID到三段版本的字典，不是SemVer范围表达式 |
| `conflicts` | 不允许同时启用的模组ID | 字符串数组 |
| `modules` | 内部模块名到Lua路径 | 模块名小写字母开头，其后允许数字、点、下划线、连字符 |
| `settings` | 注入`context.config`的静态配置 | JSON字典，修改ZIP后重启；没有通用游戏内编辑器 |
| `capabilities` | 显式能力 | 当前仅支持`mcp.tools`，不能重复 |
| `nativeContentFile` | 原生内容声明 | 模组内`.json`文件，格式见[原生内容](NativeContent.md) |

依赖至少达到所写版本且必须启用；只声明直接依赖才能读取其服务和规则。清单不是游戏存档，修改不会自动调整已保存的物品。

## Markdown内容

详细说明写在独立的Markdown文件中，用`descriptionFile`引用。推荐顺序为功能简介、使用方式、配置、依赖、游戏版本、限制和验证情况。把源码配置和游戏内编辑区分清楚，不宣称未验证的射击、护甲、掉落或模型功能。

解析由Markdig完成。当前原生UI渲染器处理标题、段落、无序与有序列表、引用、分隔线、代码块、行内代码、强调、删除线、链接文本和表格。不同标题、列表缩进和代码块均由结构化节点布局，不能靠在纯文本中手工加颜色代替解析。链接不会自动打开外部网页，图片只提供文本替代；不是完整网页浏览器，不支持任意HTML、JavaScript或远程图片加载。

建议使用紧凑表格和较短代码行，检查窄分辨率时的换行、裁剪和滚动条。游戏UI实测与离线解析测试是不同层面的验证。
